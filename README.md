# Bar El Gallego — Landing web

Landing web de una sola página para Bar El Gallego, en C. Lapilli, La Laguna (Santa Cruz de Tenerife).

## Contenido
- `index.html` — página completa (HTML, CSS y JS en un único archivo, sin dependencias externas de build).

## Desplegar en Vercel
1. Entra en https://vercel.com e inicia sesión con tu cuenta de GitHub.
2. "Add New… → Project" y selecciona este repositorio (`bar-el-gallego-web`).
3. Framework Preset: **Other** (sitio estático). No hace falta build command ni output directory: Vercel sirve `index.html` directamente.
4. Deploy.

Cada vez que se actualice `index.html` en este repositorio, Vercel vuelve a desplegar automáticamente.
